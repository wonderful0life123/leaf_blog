# 第二轮：隐藏歌单按需渲染（2026-10-18）

在第一轮本地优化基础上继续。此次业务变更仅 `src/components/features/MusicPlayer.astro`，12 行新增、2 行删除；先前未提交工作完整保留。没有推送、部署或操作生产数据。

## 定位与改动

同一页有导航及侧栏共 3 个 MusicPlayer 视图。原实现收到 fm:init 时，不论列表抽屉是否打开，都复制整份歌曲 DOM。300 首歌因此生成 900 行。

改为每个视图首次打开列表时才生成歌曲行；闭合期间只记列表待更新，打开时读取音乐管理器的最新歌单和曲目序号。已生成的同一列表再次展开不重建。列表集中在 DocumentFragment 中构造后一次插入；闭合时不再扫描全部歌曲行更新选中样式。搜索返回空列表也清除过时行。

音乐管理器、获取歌单、播放/暂停/前后切歌、音量、歌词及播放器外观未改。第一次展开的列表工作被延后，而非凭空消除；打开过的歌曲 DOM 继续保留，避免反复创建。本轮不宣称减少网络请求或所有后台开销。
